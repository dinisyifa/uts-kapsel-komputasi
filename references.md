# Referensi Data Spice & Sip

Nilai gizi di Spice & Sip adalah **estimasi untuk keperluan simulasi**, bukan saran gizi atau nilai yang terjamin akurat 100%.

## Makanan (menu id 1–10)

Nilai gizi tiap makanan dihitung dari komposisi bahan penyusunnya per porsi.

https://data.mendeley.com/datasets/8b4ztns76h/2

## Minuman (menu id 11–20)

Nilai gizi minuman diambil dari data nutrisi minuman Starbucks ukuran **Tall** (kalori, protein, lemak, karbohidrat).
